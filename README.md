# Free Claude skills by Try It, Build It

[![skills.sh](https://skills.sh/b/tryitbuildit/claude-skills)](https://skills.sh/tryitbuildit/claude-skills)

Three free, original Claude skills (Agent Skills in the open SKILL.md format) for indie builders shipping real apps. They come from shipping a Chrome extension and Android apps with Claude Code. They work in Claude Code and Claude.ai.

| Skill | What it does |
|---|---|
| [play-closed-test](skills/play-closed-test/SKILL.md) | Gets a new Android app through Google Play's closed test (12 testers for 14 days) and ready to apply for production. |
| [store-listing-check](skills/store-listing-check/SKILL.md) | Reviews or writes a Chrome Web Store or Google Play listing to catch common rejection causes before you submit. |
| [claude-md-starter](skills/claude-md-starter/SKILL.md) | Writes or improves a project's CLAUDE.md so Claude Code knows your stack, commands and rules. |

## Install

**Claude Code, as a plugin** (inside Claude Code):

```
/plugin marketplace add tryitbuildit/claude-skills
/plugin install starter-skills@tryitbuildit
```

**Claude Code, by hand:** copy any folder from `skills/` into `~/.claude/skills/` (every project) or `.claude/skills/` in your repo (one project), then start a new session.

**Claude.ai:** zip a skill folder and upload it in Settings, under Capabilities.

Then just ask, for example: "Use play-closed-test to plan my Google Play closed test."
